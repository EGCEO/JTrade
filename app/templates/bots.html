Webhook API Reference (for external bots)

MethodEndpointPurpose
GET/webhook/statusRead current mode, thresholds, risk limits, unlocked networks, routers
POST/webhook/opportunitiesPush a discovered opportunity (auto-scored & filtered)
POST/webhook/heartbeatsPush bot heartbeat / state / last action
POST/webhook/tradesPush execution result & update balances
POST/webhook/balanceUpdate paper/real balance directly
POST/webhook/insightsPush a logged insight

All webhook endpoints require the X-API-Key header matching the WEBHOOK_API_KEY secret.

Connection Setup Guide

Base URL
Auth HeaderX-API-Key: <your-webhook-api-key>

External bots must send the X-API-Key header on every request. Get the key from the Secrets page (WEBHOOK_API_KEY).

1. Test Connection

# Verify API key is valid
curl -H "X-API-Key: YOUR_KEY" /webhook/test

2. Read Current Status

# Bot reads mode, thresholds, risk limits, unlocked networks
curl -H "X-API-Key: YOUR_KEY" /webhook/status

3. Push Heartbeat

curl -X POST -H "X-API-Key: YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"bot":"scanner","state":"running","last_action":"scanning base"}' \
  /webhook/heartbeats

4. Push Opportunity

curl -X POST -H "X-API-Key: YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"pair":"WETH/USDC","network":"base","style":"flashloan","buy_cost":1000,"sell_proceeds":1003.50,"estimated_gas":2,"flashloan_fee":0.7,"hops":1,"confidence":0.85}' \
  /webhook/opportunities

5. Push Trade Result

curl -X POST -H "X-API-Key: YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"mode":"paper","style":"flashloan","network":"base","pair":"WETH/USDC","expected_profit":3.5,"actual_profit":3.2,"status":"filled"}' \
  /webhook/trades
